# Full Agent Framework

`full-agent-framework` includes every agent, workflow, task, and guideline in
this repository.

## Provides

- All seven production agents, including coordination, planning, engineering,
  quality, documentation, review, and Scrum support.
- All engineering and documentation workflows, including implementation, bug
  fixes, test coverage, dependency updates, reviews, pull request preparation,
  and documentation writing.
- Every shared task and guideline for worktrees, Git, testing, validation,
  reviews, and writing.

Use this toolkit when one focused toolkit is not enough, or when work needs
several roles.
