# Documentation Toolkit

`docs-toolkit` helps create, review, and publish accurate documentation.

## Provides

- The `documenter` agent for guides, reference material, examples, and docs review.
- The `writing-documents` workflow for larger documentation work.
- The `write-docs` and `review-docs-changes` tasks for focused writing and review.
- Pull request, worktree, validation, and writing-convention skills for safely
  preparing documentation changes.

Use this toolkit when the main result is documentation or user-facing text.
