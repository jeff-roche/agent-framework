# Quality Toolkit

`quality-toolkit` helps prove that software works as intended.

## Provides

- The `quality-engineer` agent for end-to-end customer workflow checks.
- The `code-reviewer` agent for finding defects, regressions, and missing tests.
- The `improve-test-coverage`, `bug-fix`, and `review-changes` workflows.
- Test planning, test implementation, validation, bug triage, review, and
  repository-convention skills.

Use this toolkit for test coverage, bug investigation, quality checks, and
evidence-based reviews.
