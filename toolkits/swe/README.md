# Software Engineering Toolkit

`swe-toolkit` supports planning, building, testing, reviewing, and delivering
software changes.

## Provides

- The `software-engineer`, `tech-lead`, and `code-reviewer` agents.
- The `implementation`, `minimal-implementation`, `bug-fix`,
  `dependency-update`, and `prepare-pull-request` workflows.
- Tasks for planning, test-driven development, implementation, testing,
  validation, review, commits, and pull requests.
- Shared worktree, Git, review, and writing conventions.

Use this toolkit for features, fixes, refactors, dependency updates, and code
delivery.
